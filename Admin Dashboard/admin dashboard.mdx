## Overview

The Admin Dashboard is used to manage Atlomy.com.

- Use [Atlomy App](./atlomy%20app.mdx) to manage content and page relationships. **For:** Content editors (researchers) and modelers.
- Use [Authentication and Authorization](./authentication%20and%20authorization.mdx) to manage users, groups, and permissions. **For:** Technical administrators.

> **Need help?** To open an account, add permissions, or troubleshoot any issues, contact your technical administrator.

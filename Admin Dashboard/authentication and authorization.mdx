## Groups

Groups let you bundle Permissions and assign them to Users in one step.

Permissions control whether a User can add, change, delete, or view data in specific sections.

### Create a group

1. Go to **Admin Dashboard > Authentication & Authorization > Groups**.
2. Click **Add Group**.
3. Enter the Group **Name**.
4. Move required Permissions from **Available permissions** to **Chosen permissions**.
5. Click **Save**.

## Users

Use this section to create User accounts and control access.

### Create a User account

1. Go to **Admin Dashboard > Authentication & Authorization > Users**.
2. Click **Add User**.
3. Enter the Username.
4. Select **Password based authentication**.
5. Enter a Password, then confirm it.
6. Click **Save**.

### Update User details and Permissions

1. Go to **Admin Dashboard > Authentication & Authorization > Users > [user's username]**.
2. Add **First name** and **Last name**.
3. Add the **Email address**.
4. Set **Active** on or off. Deactivation is preferred over deleting the account.
5. Set **Staff status** on or off. This keeps the account active but controls Admin Dashboard access.
6. Set **Superuser status** on or off. Superusers receive all Permissions.
7. Assign one or more **Groups**.
8. Assign individual **Permissions** if needed.
9. Click **Save**.

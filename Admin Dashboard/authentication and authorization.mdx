## Groups

This section allows defining sets of permissions needed for conducting certain procedures on the dashboard, such as managing lemma or model pages. These sets of permissions are allocated to groups of users, saving the need of granting each permission to each user one-by-one.

Currently, Groups include **content editors**, **model description editors**, and **model lemma editors**. Users can be granted permissions to **add**, **view**, **change**, or **delete** items/item attributes across the dashboard.

To create a set of permissions, enter **Authentication & Authorization > Groups** and click **Add Group**. Give the group a name and define its permissions by transferring them from the list of **Available Permissions** to the list of **Chosen Permissions** and vice versa.

## Users

This section allows creating new user accounts and assigning permission to each user. To create a user account, on the dashboard, enter **Authentication & Authorization > Users** and click **Add User**. Enter a username and password and click **Save**.

To edit permissions and get further information about the user account, re-enter the user’s entry. You will now be able to edit personal information, grant permissions and assign the user to groups, and define user status and dates.

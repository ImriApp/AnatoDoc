## Groups

This section allows grouping permissions needed for performing a series of actions on the dashboard. These groups can then be assigned to users, saving the need of granting them each permission one-by-one.

Users can be granted permissions to **add**, **change**, **delete**, and **view** all sorts of items in the dashboard.

### To create a group of permissions:
1. Enter **Authentication & Authorization > Groups**.
2. Click **Add Group**.
3. Enter the group **Name**. 
4. Define the set of permissions by transferring them from **Available permissions** to **Chosen permissions**.

## Users

This section allows creating user accounts and editing permissions for users.

### To create a user account:
1. On the dashboard, enter **Authentication & Authorization > Users**.
2. Click **Add User** on the upper right corner. 
3. Enter the user's username and
4. Choose **Password based authentication**.
5. Enter a password for the user.
6. re-enter the password for confirmation.
7. Click **Save**.

### To add more personal information to the user and edit their permissions:

1. Enter **Authentication & Authorization > Users > [user's username]**.
2. Add the user's **First and Last name**.
3. Add the user's **Email Address**.
4. **Activate/Deactivate** the user's account. This is preferable to deleting the user account.
5. Validate/invalidate the user's **Staff Status**. This keeps the account active but prevents the user from accessing the dashboard.
6. Grant/deny the user **Superuser Status**. This gives the user access to all permissions.
7. Assign the user to one or more **Groups**.
8. Assign the user individual **Permissions**.
9. Click **Save**.

## Configurations

Configurations keep Atlomy.com up to date. They import updated versions of the tables in Greek Lexicon DB into the Admin Dashboard. This process creates, deletes, and modifies Lemma Pages in Atlomy.com.

Formerly, updating Atlomy.com required manually exporting each table in Greek Lexicon DB as a CSV file. These files would be saved on AWS S3 to which the dashboard would connect for importing their data. Nowadays, an API allows direct connection from the dashboard to our workspace on Coda, and it draws information only from the Lemma Pool, as it includes all the necessary data from the other tables. This colectively makes the configuration process quicker and more comprehensive.

### To run a configuration

1. Make sure that all Lemmas in the Lemma Pool are attributed a properly formatted Name, Translation, and Transliteration. This is crucial for the configuration to run without fail.
2. Enter **Admin Dashboard > Atlomy App > Configurations > Run script**.
3. Under **Content**, Change the dates in the default script to achieve a faster configuration time:

```
{"creation_date_offset": "02/15/2021", "update_date_offset": "04/27/2021"}
```

This script sets to update the dashboard with all Lemmas in the Lemma Pool that were created since February 15, 2021, and all those modified since April 27, 2021. Change these dates to more recent ones, so that only Lemmas created or modified since will be imported to the dashboard.

4. Under **Use Coda**, make sure **yes** is selected.
5. Under **Status**, change **stopped** to **running**. (This will return to **stopped** automatically once the configuration is finished.)
6. Click **Save**.

After clicking save, the `add_data` script is run, which includes these steps:

1. Elastic is updated with the additions, deletions, and changes in the Lemma Pool.
2. The Lemmas in Elastic are compared with the Lemma Pages in the dashboard.
3. Based on this comparison:
 * Lemmas in Elastic that do not have a corresponding page in the dashboard are copied to the dashboard from Elastic.
 * Lemmas in Elastic that have a corresponding page in the dashboard are updated to match Elastic.
 * Lemmas in Elastic that were marked for deletion in the lemma pool prior to running the configuration are de-activated on the dashboard, and they will not appear in search results nor in responses from the Lemmas API.

Atlomy.com will be fully updated within 10-15 minutes of clicking save.

## Feedbacks

This is an inbox for feedbacks entered by Atlomy's users. Each item is a response, containing the responser's email address, their institute (if them entered it), the content of their feedback, and checkmarks for following up on their input.

## Jobs

Jobs are reports (in JSON format) created automatically in the admin dashboard after each Configuration. They report on the successes, warnings of failure, or failures in the configuration process.

Warnings of Failure happen when Lemmas lack complete metadata, for example, when they lack a Short or Long Description, or a list of References. Failures, however, happen specifically when a Lemma lacks a Name, Translation, or Transliteration (read further on metadata in the [Coda Guide](../Greek%20Lexicon%20DB/lemma%20pool.mdx)).

## Lemmas

This section of the dashboard contains all Lemma Pages imported from the Lemma Pool. It is used solely to add typography to Short and Long Descriptions, which is not imported as part of the Configuration process.

Creating Lemma Pages in the Admin Dashboard or editing them there in a way other than adding typography is possible but strongly discouraged. Lemma Pages should be created and edited in the lemma pool and then imported to the dashboard through a configuration.

Deleting a Lemma Page will break any reference to its Lemma. This includes URLs, Model Lemmas, and search results, which will no longer function or return results. Instead, Lemma Pages are de-activated. To de-activate a Lemma Page, its Lemma should be marked for deletion in the Lemma Pool, and then a Configuration should be run. This way, the Lemma Page will not appear in search results nor in responses from the Lemmas API.

## Model lemmas

This section lists connections between models and lemmas - each row is a single connection between a Lemma Page and a Model Page, reflecting the list of connections in (Modelling Instructions Sub-Items)[../Visualizations/visualizations.mdx#backend-tables].

These connections tell Lemma Pages to link to 3D Models that feature them, and they tell Model Pages to link to Lemmas that are depicted in them. This is crucial for the user experience of Atlomy.com, as it allows users to easily navigate between Lemma and Model pages.

### To connect a model page and a lemma page:

1. Enter **Admin Dashboard > Atlomy App > Model Lemmas**.
2. Click **Add Model Lemma** on the upper right corner.
3. Select the **Model Page** and the **Lemma Page** that you want to connect.
4. Click **Save**.

Objects in the 3D model that are named the same as the lemma page will link to it when clicked on.

## Models

Model Pages are the pages that show 3D models and their information. They are created and managed in this section.

### To create a new model page:

1. Enter **Admin Dashboard > Atlomy App > Models**.
2. Click on **Add model** on the upper right corner.
3. Enter the required information:
 * **Model Name**, following the formula `[ancient author] - [system name]` (for example, `Galen - Hindlimb`).
 * **URL** of the location of the 3D model in **AWS S3**.
 * The **Ancient Author**'s name.
 * The **Author**'s name (the researcher who designed the model).
4. Under **Show in home**, select whether the 3D Model is to be published on Atlomy.com.
5. Enter **Images**:
 * **URL**s of the thumbnails stored on AWS S3. There are three thumbnail sizes - one for the home page (168x140px), one for a detailed view in the lemma pages (246x180px), and one for search (50x30px).
 * The model's **Description** as it was written by the philologist or [AMTA](../AMTA/amta.mdx).
 * Zoom ration and position.
6. Click **Save**.

## Pages

This sections manages the pages of Atlomy.com that are not lemma pages nor model pages.

* **Author Pages** show information about Aristotle, Galen, Hippocrates, and Celsus, and they are accessed by the user through the reference list in any lemma page.
* **Treatise Pages** show information about treatises, such as Hippocrates' On the Heart and Aristotle's History of Animals, and they are accessed by the user through the reference list in any lemma page.
* **Other Pages** are independent of the 3D Atlas and the lexicon, and they are accessed by the user through the home page. Examples of these pages are the **How to use Atlomy** and **About** pages.

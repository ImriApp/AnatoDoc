## Overview

ATLOMY is a multilingual lexicon and Interactive 3D Atlas of ancient anatomy. It also includes documentation of Reenactments of surgical procedures described by ancient physicians.

## Lexicon: Search and Indexes

ATLOMY is organized around Lemmas, the canonical dictionary form of words that appear in ancient sources in different inflections and contexts. Each Lemma may have multiple meanings and uses.

Every Lemma has a citable Lemma Page with:

* lexical, interpretive, and bibliographic information
* a searchable list of references, quotations, and translations
* links to related 3D Atlas Models where the Lemma is visualized

You can search in four languages: English, Latin, Ancient Greek, and Classical Arabic.

To search, type a word in the search bar. For example:

* heart / kardia / καρδία
* vessel / vein / phleps / φλέψ / عِرْق
* artery / artēria / ἀρτηρία

As you type, ATLOMY suggests matching Lemmas. Select a suggestion to open its Lemma Page.

If your term does not appear, or if you want all possible matches, select Search or press Enter. ATLOMY then shows all Lemmas relevant to your query.

Indexes list all Lemmas in the atlas and allow sorting by different criteria.

| Index | Description |
| --- | --- |
| Terms | All lexicon entries, sorted by English transliteration |
| English Index | All lexicon entries, sorted by English translation |
| Greek Lemma | Lemmas from ancient Greek texts |
| Arabic Index | Roots from Arabic texts (historically translated from Greek texts) |
| Latin Lemma | Lemmas from ancient Latin texts |

On each index and search results page, the available filters are Author, Treatise, and System.

Tip: In Arabic, one root may correspond to several terms. Select a root to open its Lemma Page and review References and quotations for the derived terms.

## Interactive 3D Atlas

ATLOMY's home page currently features 10 citable 3D Models representing different body systems and layers as described in Ancient Texts, and this number is expected to grow over time. Related Models also appear on relevant Lemma Pages.

Select a model to open the 3D viewer. In the viewer, use these controls:

| Action | Control |
| --- | --- |
| Rotate model | Left-click + drag |
| Pan view | Right-click + drag |
| Zoom in/out | Mouse wheel or pinch gesture |
| Reset view | Reset button |

Left-click a body part to open its info card. Right-click for additional options, including the ability to isolate the part, hide it, make it transparent, or focus on it.

Use the layers menu at the bottom-left corner to toggle visibility of different anatomical layers.

## Guides and Re-enactments

ATLOMY includes Reenactments of Dissections described by the 2nd-3rd century physician Galen in his work *Anatomical Procedures*.

These guides include:

* Translations and interpretations of Galen's text
* Photo and video documentation of reenacted procedures

To open this material, select **Re-enactment** in the upper-right corner of ATLOMY.

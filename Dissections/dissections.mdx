## Overview

The Re-enactments section in ATLOMY.com draws information from the tables in Dissections.
After every dissection performed, a new page is created in this Dissections, with a table
for documenting all steps, texts, interpretations, photos, and videos from performing the procedure.

Each table is built a bit differently, but shares some key column:

## Overview

Dissections is a file on Coda where we document our reenactments of the surgical procedures described in Galen's texts. The documentation is based on the information we have gathered from our analysis of the texts, and it includes instructions, translations, images, videos, and observations from performing the reenactments.

Dissections is linked to Ancient Dissection - Re-enacted, an additional file on Coda which curates dissections data into per-procedure dashboards. Ancient Dissection - Re-enacted is embedded in the (Re-enactment Page)[https://www.atlomy.com/re-enactment] in ATLOMY.com..

After a dissection is performed, a new page is created for it in Dissections, with a table for documenting all steps, texts, interpretations, photos, and videos from performing the procedure.

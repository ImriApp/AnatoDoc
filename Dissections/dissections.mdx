## Overview

Dissections documents reenactments of surgical procedures described in Galen's texts. Each reenactment is recorded in a dedicated page containing a structured table of steps, source texts, translations, media, and observations.

Dissections is linked to **Ancient Dissection - Re-enacted**, a separate Coda file that aggregates this data into per-procedure dashboards. That file is embedded in the [Re-enactment Page](https://www.atlomy.com/re-enactment) on ATLOMY.com.

## Adding a New Reenactment

After performing a reenactment, create a new page in Dissections. To get started, copy an existing table rather than building one from scratch — see the reference tables below. Populate the table by filling in one row per substep.

## Table Structure

Each reenactment table may vary slightly, but all tables share the following columns:

| Column | Description |
|---|---|
| **Step** | Ordinal position of this step within the procedure. Unique per procedure; does not reset. |
| **Substep** | Ordinal position of this substep within its parent step. Resets to 1 at each new parent step. |
| **Instruction** | The action to perform at this substep, derived from analysis of the relevant passage in Galen's text. |
| **Translation** | English translation of the Galenic passage on which this substep's instruction is based. |
| **Greek Texts** | The original Greek passage on which this substep's instruction is based. |
| **Images** | Still images of this substep captured during the reenactment. |
| **Step Video Clip** | Video clip of this substep, cut from the full step recording. |
| **Full Dissection Step Timecode** | Video of the entire parent step as performed, encompassing all its substeps. |
| **Observations** | Post-reenactment observations recorded by the physician, anatomist, or researcher. |
| **Publication Instructions** | Notes on what to include or highlight in any publication reviewing this reenactment. |

## Documentation gaps to complete

The points below are still unclear from the current documentation and should be confirmed by someone with direct knowledge of the workflow.

- **Page naming convention** — Is there a required naming format for new reenactment pages, such as `Dissection-[Procedure]-[DD-MM-YY]`?
- **Table variation** — Which columns are optional, procedure-specific, or legacy, and which are canonical across all tables?
- **Step vs. substep granularity** — What rule determines when a new step starts versus when something remains a substep of the previous step?
- **Full Dissection Step Timecode** — Does this field store a timestamp, a video file, or a link, and which source recording does it reference?
- **Column ownership** — Which roles are responsible for filling each column, especially Observations and Publication Instructions?
- **Greek Texts source** — Must the Greek text link to Greek Lexicon DB entries, or is free text acceptable?
- **Media storage** — Where should images and video clips be stored, and are there file naming or format requirements?
- **Review workflow** — Does a reenactment table require review or sign-off before it is considered final?
- **Sync behavior** — Is the link to Ancient Dissection - Re-enacted automatic, or does it require manual updating after a new page is added?

## Purpose

The Greek-Arabic Lexicon records generalized Greek-Arabic lexical correspondences listed in the modern editions of Galen's Anatomical Procedures (Garofalo 1986, 2000; Simon 1906), including their early-reference framing.

These correspondences are presented as a filtered view of Ancient Word Full Reference, not as an independent source table.

## Scope

Use this table for generalized cross-language equivalences only.

Do not use this table for:

* Contextual translation evidence from annotated passages
* Automated reference generation
* Lemma-page publication content that is sourced from the Lemma Pool

## Table Schema (View Columns)

This table is a view of Ancient Word Full Reference with the following columns:

| Column | Description |
| --- | --- |
| Translation (AR) | Arabic lexical rendering in this correspondence view. |
| Translation (GK) | Greek lexical form used in the correspondence view. |
| Cross Reference | Generated or normalized textual reference carried from the source row. |
| Page | Page value from the source bibliographic location. |
| Line Number | Line value from the source bibliographic location. |
| Early Category Type | Early-edition category attribution associated with the row. |
| Translation (EN) | English translation value carried from the source row. |
| Translation German | German translation value carried from the source row. |
| Modern Edition | Modern edition attribution for the row. |
| Created by | Audit field from the source row. |
| Modified on | Audit timestamp from the source row. |

## View Semantics

Because this table is a view, it inherits all row-level provenance from Ancient Word Full Reference:

* No standalone primary key is required in this view.
* No direct foreign key to Lemma Pool is required in this view.
* Updates are made in Ancient Word Full Reference, then reflected here through view synchronization.
* Coverage is limited to rows that satisfy the Greek-Arabic lexicon view filter in the source table (that is, selected terms rather than guaranteed full-edition exhaustiveness).

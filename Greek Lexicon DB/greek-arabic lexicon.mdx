## Purpose

The Greek-Arabic Lexicon records generalized Greek-Arabic lexical correspondences listed in the modern editions of Galen's Anatomical Procedures (Garofalo 1986, 2000; Simon 1906), including their early-reference framing.

These correspondences are presented as a filtered view of Ancient Word Full Reference, where the only filter is `thisRow.[Modern Edition]=[Galen, Anatomical Procedures]`, not as an independent source table.

## Scope

Use this table for generalized cross-language equivalences only.

Do not use this table for:

* Contextual translation evidence from annotated passages
* Automated reference generation
* Lemma-page publication content that is sourced from the Lemma Pool

## Table Schema (View Columns)

This table is a view of Ancient Word Full Reference with the following columns:

| Column | Description |
| --- | --- |
| Translation (AR) | Arabic lexical value for the entry. |
| Translation (GK) | Greek lexical value aligned to the Arabic entry. |
| Cross Reference | Reference locator string from the source row; may be empty or contain one or more locators. |
| Page | Page locator from the source edition metadata. |
| Line Number | Line locator from the source edition metadata. |
| Early Category Type | Controlled lexical category label from the source row. |
| Translation (EN) | English translation value from the source row. |
| Translation German | German gloss or explanatory translation corresponding to the same row. |
| Modern Edition | Modern-edition source label for the entry. |
| Created by | Creator name recorded in the source table (user/auditing metadata). |
| Modified on | Last-modified timestamp recorded in the source table. |

## View Semantics

Because this table is a view, it inherits all row-level provenance from Ancient Word Full Reference:

* No standalone primary key is required in this view.
* No direct foreign key to Lemma Pool is required in this view.
* Updates are made in Ancient Word Full Reference, then reflected here through view synchronization.
* Coverage is limited to rows that satisfy the Greek-Arabic lexicon view filter in the source table.
* The same Arabic entry can appear in multiple rows when aligned to different Greek forms, references, or locations.

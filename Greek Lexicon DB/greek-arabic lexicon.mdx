## Purpose

The Greek-Arabic Lexicon records generalized Greek-Arabic lexical correspondences listed in the modern editions of Galen's Anatomical Procedures (Garofalo 1986, 2000; Simon 1906), including their early-reference framing.

These correspondences are not context-specific translations from ATLOMY corpus passages. For that reason, they are maintained outside Ancient Word Full Reference and outside the Lemma Pool.

## Scope

Use this table for generalized cross-language equivalences only.

Do not use this table for:

* Contextual translation evidence from annotated passages
* Automated reference generation
* Lemma-page publication content that is sourced from the Lemma Pool

## Gaps and Missing Information

The current documentation does not define:

* The exact column schema for this table
* Whether entries should link to Lemma Pool lemmas through a controlled foreign key or remain standalone
* Whether all cited editions are fully covered or only selected terms

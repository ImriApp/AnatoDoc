## Purpose

The Lemma Pool is the central output table of the Lexicon DB. It aggregates data from Ancient Word Full Reference and organizes it as lemma entries.

Each lemma contains transliteration, single-gloss English translation, descriptive content, and linked automated references from source passages.

After configuration, this dataset is imported into the Admin Dashboard to create or update lemma pages.

## Columns

<table>
    <tr>
        <td>Lemma</td>
        <td>The dictionary form of an ancient word (see details below)</td>
    </tr>
    <tr>
        <td>Transliteration (LA)</td>
        <td>Latin-script transliteration of the lemma, following the source-language transliteration rules in the style guide.</td>
    </tr>
    <tr>
        <td>Translation (EN)</td>
        <td>A single-gloss English translation representing the lemma's core meaning in the ATLOMY corpus context.</td>
    </tr>
    <tr>
        <td>Alternative Spelling</td>
        <td>Variants of how the lemma is spelled across the ancient texts.</td>
    </tr>
    <tr>
        <td>Source Language</td>
        <td>The language of the lemma: Ancient Greek, Classical Arabic, or Latin. (Foreign Key)</td>
    </tr>
        <tr>
        <td>Related Terms</td>
        <td>Semantically or functionally related lexical entries associated with the lemma.</td>
    </tr>
    <tr>
        <td>Short Description</td>
        <td>The introductory paragraph of the lemma to be shown at the top of its lemma page.</td>
    </tr>
    <tr>
        <td>Long Description</td>
        <td>The deep-diving description of the lemma, its usages, appearances, meanings across contexts, and more.</td>
    </tr>
    <tr>
        <td>Automated References</td>
        <td>An automated list of all occurrences of the lemma in the ancient texts, reflected from rows in Ancient Word Full Reference where this lemma is assigned. (Foreign Key)</td>
    </tr>
        <tr>
        <td>Aggregated Translations</td>
        <td>An automated list of contextual translations aligned with the same occurrences listed in Automated References. (Foreign Key)</td>
    </tr>
</table>

## Publication Role

The Lemma Pool is the publication source for lemma pages in the Admin Dashboard pipeline.

## Naming, Tranlating, and Transliterating Lemmas

### Ancient Greek Lemmas

#### Naming conventions for Ancient Greek Lemmas changes according to the part of speech:

* For **Verbs** write the first principle part the lemma's dictionary entry. For example, `τείνω`, `διαιρέω`, `εἰσέρχομαι`
* For **Nouns** write the full dictionary entry in this order, separated by commas: nominative singular form, hyphened genitive singular suffix or full genitive singular form, and the grammatical gender indicated as m., f., or n. For example: `ὀστέον, -ου, n.`, `φλέψ, φλεβός, f.`
* For **Adjectives** write the full dictionary entry as it appears in an ancient greek dictionary. For example: `μακρός, -ά, -όν`, `μέγας, μεγάλη, μέγα`, `αἱματώδης, -ες`
* For any other part of speech write the basic dictionary form.

#### Translating Ancient Greek Lemmas 



#### Transliterating convenstions:

##### Consonents:

* `χ` - `ch`
* `ττ` - `ss`
* `γγ` - `ng`
* `γχ` - `nch`
* `γξ` - `nx`

##### Vowels:

* `ι` - `i`
* `ᾰ` - `a`
* `ᾱ` - `ā`
* `ε` - `e`
* `η` - `ē`
* `ο` - `o`
* `ω` - `ō`
* `υ` - `Y`
* `ου` - `ou`

### Latin Lemmas

For **Nouns** write the nominative singular form only.

## Naming, Tranlating, and Transliterating Lemmas

### Ancient Greek Lemmas

#### Naming conventions for Ancient Greek Lemmas changes according to the part of speech:

* For **Verbs** write the first principle part the lemma's dictionary entry.\
For example, `τείνω`, `διαιρέω`, `εἰσέρχομαι`
* For **Nouns** write the full dictionary entry in this order, separated by commas: nominative singular form, hyphened genitive singular suffix or full genitive singular form, and the grammatical gender indicated as m., f., or n.\
For example: `ὀστέον, -ου, n.`, `φλέψ, φλεβός, f.`
* For **Adjectives** write the full dictionary entry as it appears in an ancient greek dictionary.\
For example: `μακρός, -ά, -όν`, `μέγας, μεγάλη, μέγα`, `αἱματώδης, -ες`
* For any other part of speech write the basic dictionary form.

#### Transliteration convenstions:

The transliteration system chosen for the Atlomy corpus is the DIN 31635:

`ء - ʾ` `ب - b` `ت - t` `ث - ṯ` `ج - ǧ` `ح - ḥ` `خ - ḫ` `د - d` `ذ - ḏ` `ر - r` `ز - z` `س - s` `ش - š` `ص - ṣ` `ض - ḍ` `ط - ṭ` `ظ - ẓ` `ع - ʿ` `غ - ġ` `ف - f` `ق - q` `ك - k` `ل - l` `م - m` `ن - n` `ه - h` `و - w` `ي - y`

DIN 31635 was chosen because each letter is independant - they do not require combinations of two or three letter to represent a single consonent. As the root, the transliteration is written three consenent together without space between them.\
For Example, `رجل` is transliterated as `rǧl`.

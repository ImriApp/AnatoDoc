## Reference Style

When entering source data, use the standard scholarly citation pattern for the edition in question so the generated reference renders correctly.

### General pattern

Use this order unless a source has a well-established exception:

`Author abbreviation, Work abbreviation locator(s) [parallel edition citation] [edition label]`

Keep the citation elements in the order used by the source edition. Do not normalize different scholarly numbering systems into one another.

### Common citation forms

* **Standard author + work + locator + parallel edition citation**

	Example: `Hipp., Nat. Hom. 1 (164,2 Jouanna = VI.32 L.) (Littre)`

	Use this form when the main citation is followed by a parenthetical parallel citation to a modern edition and, optionally, a second edition label in parentheses.

* **Edition with a different chapter numbering system**

	Example: `Hipp. Morb. sacr. 16.4 = 19 Jones (29,17 Jouanna = VI.390 L.)`

	Use the `=` sign to show the equivalent locator in the edition being cited when that edition uses a different numbering system. Mark this as an exception only when the edition is not aligned with the standard chapter numbering. This is the only treatise in the current system that requires this complication.

* **Parallel citation with an edition siglum**

	Example: `Gal., PHP I.7.1 (82,12 De Lacy = V.189 K.)`

	If the edition siglum is not obvious, define it on first use. For example, `K.` means `Kühn`.

* **Simple edition citation**

	Example: `Gal., AA VII.4, 254,2 Simon`

	Use this form when the work is cited directly from a single edition without a second parallel reference.

* **Canonical ancient locator**

	Example: `Arist. HA III.5, 515a27`

	Preserve canonical locator systems such as Bekker numbers exactly as they appear in the source tradition.

### Practical rules

* Keep author abbreviations and work abbreviations exactly as established in the source tradition.
* Use commas, periods, and parentheses as required by the citation tradition of the edition.
* Use `=` only for equivalent locators or edition equivalences, not as a general separator.
* Add edition labels or sigla only when they are necessary to disambiguate the source.

## Naming, Translating, and Transliterating Lemmas

### Ancient Greek Lemmas

#### Naming conventions

Ancient Greek lemmas are named according to part of speech:

* For **verbs**, use the first principal part as the dictionary headword. Example: `τείνω`, `διαιρέω`, `εἰσέρχομαι`.
* For **nouns**, use the full dictionary entry in this order: nominative singular form, hyphenated genitive singular suffix or full genitive singular form, and grammatical gender abbreviated as `m.`, `f.`, or `n.` Example: `ὀστέον, -ου, n.`, `φλέψ, φλεβός, f.`
* For **adjectives**, use the full dictionary entry as it appears in an Ancient Greek dictionary. Example: `μακρός, -ά, -όν`, `μέγας, μεγάλη, μέγα`, `αἱματώδης, -ες`.
* For any other part of speech, use the standard dictionary form.

#### Translation convention

Provide a single-gloss English translation that reflects the lemma's core meaning in the context of ATLOMY's corpus.

### Latin Lemmas

For **nouns**, use the nominative singular form only.

### Classical Arabic Roots

#### Naming convention

Write the three-letter Arabic root as a single string, without spaces. Example: `رجل`.

#### Translation convention

Use a single core semantic gloss in English.

#### Transliteration conventions

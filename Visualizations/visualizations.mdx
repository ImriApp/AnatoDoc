## Overview

Visualizations is the ATLOMY workspace for planning and tracking 3D atlas models.

For each new model, the researcher and modeler create a project page that contains:

1. A link to the Google Drive folder with source texts and assets.
2. A Table of Instructions (a filtered view of Modelling Instructions Sub-Items).
3. Increment history (what changed in each model version).
4. Researcher feedback on each increment.

Visualizations is the operational layer for model production: it combines source evidence, modeling instructions, review notes, and delivery status in one place.

## Tables of Instructions

Modelling Instructions Sub-Items contains all sub-items across all atlas projects.

For each project, Visualizations creates a filtered view of this table by Project. This filtered view is called a Table of Instructions.

Because it is a view, updates remain synchronized with the source table.

### Workflow and ownership

1. The researcher fills in the Table of Instructions (all relevant fields except <strong>Status</strong>).
2. The modeler creates each item according to those instructions and updates <strong>Status</strong> during progress.
3. When the modeler sets <strong>Status = Review</strong>, the researcher reviews the modeled item.
4. The researcher updates instructions as needed, and the modeler revises accordingly.
5. Steps 3-4 repeat until the researcher is satisfied.
6. The researcher sets <strong>Status = Done</strong> to approve the sub-item.

### Columns of a Table of Instructions

        </td>
        <td>
            English name of the anatomical unit represented in the 3D atlas.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Item</strong>
        </td>
        <td>
            Parent group for the sub-item. Select from Modelling Instructions Items.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Status</strong>
        </td>
        <td>
            Current workflow state of the sub-item, updated by the modeler to keep the researcher informed.
            Allowed values: Not Started, In Progress, Review, Done, REMOVE!.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Name of Item / Sub-Item</strong>
        </td>
        <td>
            Auto-generated display name from Lemma, Transliteration, and Translations.
            Modelers copy this value into Blender when naming objects; this is the naming source used in production.
        </td>
    </tr>
    <tr>
        <td>
            <strong>System Name</strong>
        </td>
        <td>
            Anatomical system for this sub-item.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Anatomical Details</strong>
        </td>
        <td>
            Short researcher-authored anatomical description (free text).
        </td>
    </tr>
    <tr>
        <td>
            <strong>Instructions</strong>
        </td>
        <td>
            Modeling instructions from researcher to modeler (free text).
        </td>
    </tr>
    <tr>
        <td>
            <strong>Source</strong>
        </td>
        <td>
            Source basis for the interpretation and design decision in Instructions.
            Intended for both modelers and ATLOMY end users.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Certainty</strong>
        </td>
        <td>
            Researcher confidence level for Instructions and Source.
            Intended for both modelers and ATLOMY end users.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Open Issues</strong>
        </td>
        <td>
            Outstanding questions that require verification or follow-up.
        </td>

    <tr>
        <td>

        </td>
        <td>
            Discussion notes relevant to the model page.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Animal Basis</strong>
        </td>
        <td>
            Source animal anatomy used to derive the human reconstruction, when applicable.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Insights / Emphasis</strong>
        </td>
        <td>
            Key emphasis points from researcher to modeler.
        </td>
    </tr>
    <tr>
        <td>
            <strong>Project</strong>
        </td>
        <td>
            Official project name for the 3D model.

    </tr>
    <tr>
        <td>
            <strong>Owner</strong>
        </td>

    </tr>
    <tr>
        <td>

            Lemma representing this sub-item in the source text.
        </td>
    </tr>

        <td>
            <strong>Translations</strong>
        </td>

    </tr>
    <tr>
        <td>
            <strong>Transliteration</strong>

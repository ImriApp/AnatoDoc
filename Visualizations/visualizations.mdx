## Overview

Visualizations is where ancient texts are reimagined as 3D models.
When a researcher and a modeler start working on a new model,
they open a new page for it in Visualizations, where they keep resources,
track tasks, and document progress. Each model page contains subpages with:

* A link to a Google Drive folder containing the texts on which the model is based
* A table of instructions, where the researcher instructs the modeler what body parts comprise the model and how they are positioned in it. All tables of instructions are views of - and so are synched to - the central table Modelling Instructions Sub-Items (see below).
* Workflow documentation of each increment or modification done to the model
* Feedback from the researcher regarding the latest increment or modification

    <tr>

        </td>

<table>
    <tr>

## Tables of Instructions

Modelling Instructions Sub-Items lists all body parts from all models in the atlas.
For each new 3D project, a view of Modelling Instructions Sub-Items is created in the
designated page of this project. These views, filtered only by project name of each sub-item,
are called tables of instructions.

### Columns of a Table of Instructions

<table>
    <tr>
        <td>
            Sub-Item
        </td>
        <td>
            The English name of the sub-item, representing it in the 3D atlas.
        </td>
    </tr>
    <tr>
        <td>
            Item
        </td>
        <td>
            The group of sub-items that the sub-item belong to. Select from the list of the entries in Modeling Instruction - Items.
        </td>
    </tr>
    <tr>
        <td>
            Status
        </td>
        <td>
            The status of the modeler’s work on this item - to indicate when they have began modelling a part,
            or when a draft or new version of the part is ready and should be reviewed by the researcher.
        </td>
    </tr>
    <tr>
        <td>
            Name of Item / Sub-Item
        </td>
        <td>
            Filled automatically from the columns Lemma, Transliteration, and Translation.
            The text in this column is copied by the modeler into Blender as the name of an item.
        </td>
    </tr>
    <tr>
        <td>
            System Name
        </td>
        <td>
            The system to which the sub-item belong to
        </td>
    </tr>
    <tr>
        <td>
            Anatomical Details
        </td>
        <td>
            A brief description of the sub-item according to the researcher (free text)
        </td>
    </tr>
    <tr>
        <td>
            Instructions
        </td>
        <td>
            The instructions of the researcher to the modeler for each sub-item as for what should they (free text)
        </td>
    </tr>
    <tr>
        <td>
            Source
        </td>
        <td>
            The best indication for the basis and level of clarity of the researcher’s interpretation and design
            decisions for this part listed in Instructions. This information is aimed both for the modeler ATLOMY’s users.
        </td>
    </tr>
    <tr>
        <td>
            Certainty
        </td>
        <td>
            The degree of certainty of the researcher regarding their Instructions and Source.
            This information is aimed both for the modeler ATLOMY’s users.
        </td>
    </tr>
    <tr>
        <td>
            Open Isuues
        </td>
        <td>
            Notes for further checks and confirmation
        </td>
    </tr>
    <tr>
        <td>
            Commentary
        </td>
        <td>
            Any relevant points for discussion in the model page
        </td>
    </tr>
    <tr>
        <td>
            Animal Basis
        </td>
        <td>
            The animal from whose anatomy the model is derived to human anatomy
        </td>
    </tr>
    <tr>
        <td>
            Insights / Emphasis
        </td>
        <td>
            Important makes from the researcher to the modeler
        </td>
    </tr>
    <tr>
        <td>
            Project
        </td>
        <td>
            The official name for the 3D model
        </td>
    </tr>
    <tr>
        <td>
            Owner
        </td>
        <td>
            The researcher overseeing the Project (see above)
        </td>
    </tr>
    <tr>
        <td>
            Lemma
        </td>
        <td>
            The lemma depicting this sub-item in the ancient text
        </td>
    </tr>
    <tr>
        <td>
            Translations
        </td>
        <td>
            The English translation of this sub-item’s Lemma (see above)
        </td>
    </tr>
    <tr>
        <td>
            Transliteration
        </td>
        <td>
            The English transliteration of this sub-item’s Lemma (see above)
        </td>
    </tr>
    <tr>
        <td>
            Formatted 3D Name
        </td>
        <td>
            The name of the item to be used as the 3D object's name on the 3D Atlas. Intended for the modeler.
        </td>
    </tr>
</table>
